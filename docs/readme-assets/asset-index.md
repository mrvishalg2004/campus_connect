# Mobile Application Visual Assets Index

This directory contains visual documentation assets prepared for the **Campus Connect (College Event Management)** React Native mobile application.

All mobile screenshots are captured directly from the live application environment running at a true native mobile viewport (**390 × 844 pt @ 2x DPR = 780 × 1688 px**) without browser chrome or desktop stretching.
